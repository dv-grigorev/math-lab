Задания

  1. Выберите y = x². Не трогая ползунки, предскажите: где окажется вершина параболы y = (x − 3)² + 2? Теперь проверьте.
  2. Почему «плюс» в скобках сдвигает график влево, а не вправо? Поставьте p = 3 и найдите x, при котором выражение в скобках равно нулю.
    Объяснение График y = f(x + 3) в точке x принимает то значение, которое исходная функция принимала в точке x + 3, то есть на 3 правее. Всё, что раньше «случалось» в точке 0, теперь случается в точке −3: график приехал на 3 влево.
  3. Для y = x сдвиг влево на 2 и сдвиг вверх на 2 дают один и тот же график. Проверьте. Почему так? Получится ли такое для y = x²?
    Объяснение (x + 2) + 0 = x + 0 + 2: для прямой y = x оба сдвига дают y = x + 2. Прямая «скользит вдоль себя». У параболы так не выйдет: (x + 2)² ≠ x² + 2.
  4. Где будут асимптоты у гиперболы y = 1/(x − 1) + 4? Сначала ответьте, потом проверьте.
  5. У y = log₂x какой из двух сдвигов меняет область определения? А у y = 2ˣ какой сдвиг меняет множество значений?
  6. Режим «Поймай график»: поймайте 5 целей подряд, двигая каждый ползунок только один раз.
