# Тригонометрическая окружность

Класс: 10
Раздел: Тригонометрия

## Цель
Ученик видит, что:
- угол — это поворот точки по единичной окружности; углы, отличающиеся
  на 360° (2π), дают одну и ту же точку;
- cos α — абсцисса точки, sin α — ордината; tg α и ctg α — точки
  пересечения прямой OP с осью тангенсов (x = 1) и котангенсов (y = 1);
- решения простейших уравнений sin x = a, cos x = a, tg x = a, ctg x = a —
  это точки окружности, где прямая y = a, x = a или прямая через центр
  пересекает окружность.

## Режимы
1. **Окружность.** Угол α задаётся ползунком (−720°…720°, шаг 15°) или
   перетаскиванием точки. Видны дуга поворота, проекции на оси,
   tg и ctg на своих осях.
   Включаются/выключаются: ось тангенсов, ось котангенсов, подписи углов
   (в градусах или радианах), значения функций (чтобы ученик сначала
   предсказывал, а потом проверял).
2. **Уравнения.** Выбор функции (sin, cos, tg, ctg) и числа a — ползунком или
   кнопками табличных значений. На окружности: прямая, точки-решения,
   промежуток, где лежит arcsin / arccos / arctg / arcctg. Ответ по
   формуле учебника: x = arcsin a + 2πn или x = π − arcsin a + 2πn
   (две серии, без (−1)ⁿ), x = ±arccos a + 2πn,
   x = arctg a + πn, x = arcctg a + πn; частные случаи (a = 0, ±1);
   |a| > 1 для sin и cos — «нет решений».
3. **Тренировка: градусы ↔ радианы.** Перевод в одну или другую сторону,
   ответ вводится с клавиатуры (кнопка π для телефона), после проверки
   угол показывается на окружности.
4. **Тренировка: уравнения.** Шаг 1 — отметить на окружности точки-решения;
   шаг 2 — выбрать формулу ответа из четырёх вариантов.

## Типичные ошибки, которые надо разрушить
- «sin 210° = 1/2» — забыли про знак в III четверти.
- «tg 90° = 1» или «= ∞» — на самом деле не существует.
- «cos x = 1/2 ⇒ x = π/3 + 2πn» — потеряна вторая точка −π/3.
- «tg x = 1 ⇒ x = π/4 + 2πn» — у тангенса период π.
- «sin x = √2 ⇒ x = π/4…» — |sin x| ≤ 1, решений нет.
