# Задачи с параметром

Класс: 10–11 (профильный ЕГЭ)
Раздел: Уравнения и неравенства

## Цель
Ученик учится видеть задачу с параметром как картинку: семейство кривых,
которое меняется вместе с a, и неподвижная часть. Ответ — это те значения a,
при которых картинка «правильная» (столько-то общих точек и т. п.).

## Подтемы
1. Линейное уравнение с параметром (ax = b: одно, ни одного, бесконечно много решений).
2. Расположение корней квадратного трёхчлена (оба больше M, по разные стороны от M,
   на отрезке; условия через D, вершину и f(M)).
3. Прямая и окружность (касание, число общих точек; пучок прямых через точку,
   параллельные прямые).
4. Метод областей и графический метод:
   - в плоскости (x; a): прямая a = const скользит по картинке;
   - в плоскости (x; y): движущаяся/растущая фигура против неподвижной.

Подтемы появляются по одной. На сайт попадают только готовые.
Готовы: «Расположение корней квадратного трёхчлена» (памятка, задания, разборы, генераторы),
«Прямая и окружность» (то же), «Графический метод в (x; y)» (без памятки: разборы и генераторы).
У подтемы без памятки вкладка «Памятка» скрыта.

## Устройство подтемы — три вкладки
- **Памятка** — короткая теория + живые иллюстрации с ползунком a.
- **Разборы** — 2–3 прототипа. Решение по шагам, на каждом шаге график
  показывает именно то, о чём текст (нужное значение a, подсвеченный элемент,
  отрезок-расстояние и т. п.).
- **Практика** — задача из банка, ученик вводит ответ, проверяет себя.
  После проверки: верно/неверно, правильный ответ, карта ответа, график
  с ползунком a, решение по шагам.

## Карта ответа
Ось a под графиком, раскрашенная по числу решений (0, 1, 2, …, ∞).
На ней бегает текущее a. После проверки на ней же показаны ответ ученика
и правильный ответ, расхождения подсвечены.

## Ввод ответа
Поле + кнопки ∪ ∞ √ ( ) [ ] { } ; −.
Понимает: `(-∞; -2) ∪ {0} ∪ [3; 2√2]`, `a ∈ (1; 5]`, `U` вместо ∪, `inf`,
`sqrt(2)`, `∅`/`нет`, `ℝ`. Введённое сразу рисуется на оси.
Сравнение — как множеств: `2√2` = `√8`, `(1; 2) ∪ [2; 3)` = `(1; 3)`.

## Банк заданий
- Генераторы для простых номеров: случайные коэффициенты, точный ответ
  считается программой (числа вида (p + q√d)/n).
- Задачи учителя — вносятся через «Конструктор задач» (отдельная страница
  `labs/parameters/editor.html`), хранятся в `bank/teacher.js`.

## Формат задачи (общий для генераторов и учителя)
- `text` — условие; формулы в `$…$` пишутся «по-школьному» (`x^2`, `sqrt(x)`, `|x|`).
- `plane` — `xy` или `xa`.
- `eq` — две части системы; каждая — одна или несколько кривых
  (`y = |x| - 2`, `x^2 + y^2 = 4`, `y = 2 - |x| при |x| <= 2`).
  В плоскости `xa` вторая часть — сама прямая a = const, её писать не надо.
- `ask` — что требуется: `=1`, `=2`, `>=1`, `=0`, `inf`; можно с условием
  на x (`=2 при x > 1`) и несколько условий сразу.
- `answer` — правильный ответ в той же записи, что вводит ученик.
- `solution` — шаги решения: текст + что показать на графике.

## Проверка банка (автоматически, перед публикацией)
Для каждой задачи учителя и для нескольких задач каждого генератора программа
численно считает число решений при тысячах значений a и в концах промежутков
ответа и сверяет с записанным ответом. Неверный ответ — публикация блокируется.
Та же проверка работает в конструкторе прямо при вводе задачи.

## Типичные ошибки, которые надо разрушить
- Потеря граничных значений (касание) и лишние скобки/квадратные скобки.
- «a = 0 можно не рассматривать» в уравнениях, где старший коэффициент с a.
- Для корней трёхчлена — условие только на D и вершину, без f(M).
