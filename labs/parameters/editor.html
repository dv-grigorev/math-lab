    Как решаем графически
    Диапазон ползунка a и окно графика
    Диапазон a можно не заполнять: он подберётся сам так, чтобы были видны все особые значения. Окно графика по умолчанию — от −6 до 6.
    Решение по шагам Текст шага и значение a, которое покажет график. Нажмите на шаг справа в превью — увидите его.

    Как сохранить в банк

    1. Нажмите «Скачать teacher.js» — в файле все задачи из списка выше.
    2. На GitHub откройте репозиторий math-lab, переключитесь на ветку dev, папка labs/parameters/bank → Add file → Upload files, перетащите скачанный файл, Commit changes.
    3. Автопроверка сама пересчитает все ответы. Если всё сходится — откройте pull request dev → main и нажмите Merge: задачи появятся на сайте. Если нет — GitHub покажет, в какой задаче ошибка.

    Или просто пришлите файл Claude — он добавит его сам. Пока вы работаете, черновик хранится в этом браузере и не пропадёт при перезагрузке страницы.
