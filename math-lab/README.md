# Математическая лаборатория

Банк интерактивных тренажёров по школьной математике.

## Посмотреть у себя
Распакуйте архив и откройте `index.html` двойным кликом. Интернет не нужен.

## Опубликовать (GitHub Pages)
1. Создайте аккаунт на github.com и новый репозиторий `math-lab` (Public).
2. Загрузите в него содержимое этой папки (кнопка «Add file → Upload files»
   или `git push`).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/math-lab/`.

Проверьте, что ссылка открывается у учеников без VPN. Если нет — ту же папку
можно выложить на любой статический хостинг (Netlify, Yandex Object Storage).

## Добавить новый тренажёр через Claude Code
1. Откройте папку проекта в Claude Code (он сам прочитает `CLAUDE.md`).
2. Создайте `labs/<название>/spec.md` с ТЗ (образец — `labs/graph-shifts/spec.md`).
3. Напишите: «Сделай тренажёр по labs/<название>/spec.md, по образцу graph-shifts».
4. Проверьте результат, поправьте словами, опубликуйте (`git push`).
